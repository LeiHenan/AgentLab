# 探照灯工作法（证据链优先）

**铁律：你的假设不是结论。** 允许提出方向与假设（包括从第一性原理推出来的），但任何"新方向"在给出
「验证计划 + 成本上界 + 停止判据」之前只是候选，**不得写成课题、推荐或结论**。

工具链是一条**不可跳步**的流水线：

```
searchlight_init → searchlight_run → searchlight_claim → searchlight_occupancy
                 → searchlight_falsifier(design → resolve) → searchlight_topic
```

`searchlight_stop action=overview` 可随时只读恢复上下文。

## 每步的硬判据（工具会强制执行，不要试图绕过）

1. **域判据（init）**：`第一代只优化速度、对正确性/可复现性失明` 是**假设 H1**，不是定律。
   每个新子领域必须重新检验：抽 N 篇代表作，统计"以吞吐/延迟/加速比为唯一主结果"的比例。
   比例低 → H1 不成立，说明这条缝可能已被占，**必须另找缝隙**。
2. **噪声底线（run）**：观察到一次差异 ≠ 差异存在。反常类必须给同配置重复观测（≥3 次），
   工具自行算分布与效应量，**不足 3× 一律判为「噪声待查」**，不得进入后续环节。
   不要为了通过而调阈值——阈值是方法论的落点。
3. **自证伪四问（run）**：声称"发现"前必须回答：空桩？单变量？环境能否解释？能否从原始日志重算？
   任一为 false → 降级为"待查缺陷"。**先证伪自己，再证伪别人。**
4. **量化陈述（claim）**：三要求——有数字、有**参照系**、能推出可检验的设计含义。缺一不可。
5. **占位核查（occupancy）**：阶段一三态 `none / partial / quantitative`；后两态必须做阶段二，
   回答"占据了框架的人**解决了问题吗**"。判定只有三种：已被解决（放弃）/ 框架已占但问题未解决 / 未被占。
   - **检索盲区不是空位**：覆盖不到在审/闭源层时，结论只能是「在本 agent 可见范围内未被占」，
     并**原样带进课题卡**。
   - 判据 (a)"旧问题未被解决"（须真读过占据文献）是上位判据；(b)"角度被忽视"是下位启发式，
     **不得用 (b) 的便宜标准冒领 (a) 的结论**。
6. **预注册证伪（falsifier）**：先 `design` 写死继续/停止判据 + 成本上界 + **可证伪性说明**
   （什么样的观测会与主张不一致）；实验跑完才 `resolve` 登记带数字的证据。
   设计阶段夹带结果字段 = 数据泄漏，工具直接拒绝。同一证伪不得覆盖结果。
7. **课题升级（topic）**：只有 **[空位成立] ∧ [预注册证伪存活] ∧ [预算未超]** 三者同时满足才放行。
   这是"假设 ≠ 结论"的落地点。
8. **停止与升级（stop）**：四类必须分开——① 封存型（容量耗尽）② **重跑型（测量不可靠，不得封存）**
   ③ 扩容型（需新变量/新规模，转资源申请）④ 零异常出口（先查度量分辨率）。
   **不得自行封存候选**（不可逆决定交人类）；连续 3 个候选全灭 → 报告"本环境不产出空位"，
   而不是继续换方向硬找。

## 空位的两个来源（不要混用）

- **(a) 旧问题未被解决**：高价值、高成本，必须读过占据文献并证明它没解决；
- **(b) 角度被忽视**：低成本启发式，必须叠加占位核查。

当 H1 在当前子领域成立时，历史高回报的搜索偏置是**测量 / 正确性 / 可复现性**这条缝——但它是偏置，不是保证。

## 数字溯源

任何进入结论的数字必须能追溯到：指标定义、采集位置、可复现命令、窗口与样本量（含预热）、
配置点、环境、**敏感性（未扫的必须显式写"未做敏感性扫描"）**、噪声底。
四类隐性口径重点提防：代理量、样本不足、实现空桩（返回常量/未通电分支）、**参数相关的结论**（换个参数就翻转符号）。

## 读取账本

账本落在工作区 `.dsh-searchlight/<projectId>.json`，纯 JSON，可直接 read 查看全部
实验、异常、候选、证伪与课题卡。**它跨会话持久，是新会话恢复上下文的唯一入口**——
不要凭记忆续接上一轮。
